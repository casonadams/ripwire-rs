Documentation

ripwire-rs is a high-throughput code intelligence engine and context router for AI coding agents and developers. It indexes 36 programming languages via Tree-Sitter to construct directed call graphs, calculate symbol impact via Personalized PageRank, slice intra-procedural dataflow, and enforce pre-commit quality gates.

Lineage & Attribution: ripwire-rs is an idiomatic Rust port and rewrite of the original C++23 ripwire engine authored by David Brewster at Red Hat Emerging Technologies. We gratefully acknowledge their foundational work on token-budgeted streaming call graphs, pre-commit delta heuristics, and deterministic code intelligence for AI agents.
100% Local & Zero Telemetry Guarantee: ripwire-rs is completely offline-by-design. It makes zero network calls, contains zero analytics or telemetry, and performs zero model training. Your proprietary source code never leaves your workstation. It functions purely as an in-process local AST parser that emits structured context to stdout or stdio MCP for the agent harness or LLM you control. Automated secret redaction is active by default.

brew install casonadams/tap/ripwire-rs

echo "deb [trusted=yes] https://casonadams.github.io/homebrew-tap/apt stable main" | sudo tee /etc/apt/sources.list.d/casonadams.list

curl -fsSL https://casonadams.github.io/homebrew-tap/rpm/casonadams.repo | sudo tee /etc/yum.repos.d/casonadams.repo

ripwire-rs CLI Reference

The ripwire-rs binary offers both direct flag-based execution and structured workflow subcommands.

ripwire-rs [PATH] [--top-k <N>] [--max-tokens <N>] [--stable] [--legend <MODE>] [--cache <PATH>] [--no-cache] [--scip <FILE>]
Architecture
What It Does

Parses the repository at PATH (defaults to current directory), builds the workspace call graph across 36 languages, executes Personalized PageRank, and streams ranked symbol definitions with incoming callers as canonical XML (bounded by --top-k symbol count or --max-tokens / --pack-budget streaming limits). Automatically caches compiled call graphs in TMPDIR for sub-second repeat queries (use --no-cache for cold parse). --scip=index.scip overlays a compiler-backed SCIP index: the call sites it resolves bind exactly (prov="scip", header precise=K) and bypass the cache.

The same global --scip=PATH overlay works before or after navigate, plain or task-ranked orient, and mcp. MCP retains its indexed graph for the session. Multiline calls match the callee identifier's index line; reports preserve the call expression's start line. Unreadable or malformed indexes fail explicitly without a name-only fallback.

How It Works

Runs Tree-Sitter syntax queries in parallel via Rayon, interns symbols with Lasso, resolves call references through a multi-tier precedence ladder, and executes power iteration over a compressed sparse row (CSR) transpose in-edge matrix. Serializes binary cache payloads keyed by git HEAD SHA and file mtimes to deliver warm map responses in under 50ms on medium repos and ~600ms on 7,000+ file codebases with 60%–85% lower memory footprint than C++.

When To Use It

When first landing in an unfamiliar codebase, retrieving high-level architectural anchors, or packing dense, budget-bounded context into LLM prompts without hallucinated dependencies.

ripwire-rs --quality-delta
Safety Gate
What It Does

Compares uncommitted working tree changes against git HEAD (or a pinned baseline) and reports code quality regressions across complexity, duplication, dead code, and contract breaks. Exits non-zero if gating regressions are detected.

How It Works

Computes multi-vector quality snapshots (Campbell cognitive complexity via cccc, cyclomatic complexity, Type-1/2/3 AST clones, arity changes) on both revisions and diffs the findings, filtering out expected churn and self-registering test macros.

When To Use It

In pre-commit hooks, local developer validation before git push, or automated CI/CD merge-safety pull request checks.

Linter & SARIF

When To Use It

How It Works

When To Use It

How It Works

Extracts exact byte spans from the underlying source files, resolving qualified selectors (`Type::method`, `file:name`, `file:LINE`), and streams the function bodies to stdout.

When To Use It

When drilling down from architectural map summaries to implementation details of specific core functions.

ripwire-rs --dead-code
Architecture
What It Does

Scans the entire workspace call graph and identifies internal functions and methods with zero incoming callers.

How It Works

Computes in-degree matrix offsets across the graph, filtering out public library entry points and self-registering test macros.

When To Use It

During codebase refactoring, dead-weight cleanup, or technical debt audits to find safely removable internal code.

ripwire-rs --edit-check <SYM>
Safety Gate
What It Does

Verifies whether recent modifications to symbol <SYM> altered its parameter count or visibility, identifying all direct callers in the codebase that become incompatible with the new signature.

How It Works

Extracts parameter counts and visibility modifiers from the AST at both revisions. Traverses 1-hop reverse call graph edges to check if existing call sites pass matching argument arity.

When To Use It

Immediately after refactoring or modifying a public function, method, or constructor signature, before executing full workspace test suites.

ripwire-rs --affected <PATH>
Safety Gate
What It Does

Identifies exactly which test files transitively reach the changed file or symbol <PATH>, ranking them by evidence tier (edited tests, partner-named tests, call hop distance).

How It Works

Computes transitive reachability over reverse call graph edges from the target node, keeping nodes in test files (tests/, test_*, *_test.*, *.test.*, *.spec.*). Tests named after a changed file are added as partner="1" rows even with no call edge; a file with several candidate partners gets none.

When To Use It

To run a surgical, high-confidence subset of fast regression tests instead of running the entire multi-minute test suite during tight TDD loops.

ripwire-rs --hotspots
Metrics
What It Does

Ranks repository files by maintenance risk score, combining commit churn with cognitive complexity to highlight fragile, high-risk code hotspots.

How It Works

Mines git commit history with exponential half-life time decay (weighting recent revisions higher) and multiplies file commit frequency by average McCabe and Campbell cognitive complexity.

When To Use It

Prior to architectural refactoring, when scoping technical debt, or when allocating code review attention to the most defect-prone files in a repository.

ripwire-rs --dmm [REV|A..B]
Quality
What It Does

Computes the Delta Maintainability Model (DMM) scalar in [0,1], quantifying the proportion of code volume churn that made the codebase healthier.

When To Use It

In CI gates or wave reviews to track whether refactorings genuinely reduced unit risk or introduced new technical debt.

ripwire-rs --quality-panel [PRESET]
Panel
What It Does

Runs the unified 6-family quality panel (structural, lexical, confusion, historical, colocation, state) in one report ranked by distinct families fired.

When To Use It

Before major code convergence to perform a wide-angle sanity check across all quality evidence families simultaneously.

ripwire-rs --cochange [<FILE>]
Git Analytics
What It Does

Surfaces companion files that historically change together with <FILE>, detecting hidden Fowler's Shotgun Surgery coupling.

How It Works

Scans multi-file commit transactions across git history, filters out repository-wide merge-bombs (>100 files), and calculates co-change support, confidence, and surprise ratios.

When To Use It

Before editing an interface, schema, or configuration file, to guarantee that all implicit partner files (docs, test fixtures, downstream consumers) are updated in the same change.

ripwire-rs --slice <SYM[:VAR]> [--slice-flow <fwd|back|both>]
Slicing
What It Does

Traces intra-procedural def-use variable occurrences inside function <SYM>, mapping how variable <VAR> is initialized, assigned, and consumed.

How It Works

Implements the ARISE slicing algorithm (arXiv:2605.03117) over Tree-sitter AST nodes to build localized def-use chains, control dependencies, and reaching definitions in forward, backward, or bidirectional flow.

When To Use It

When debugging variable corruption, auditing taint propagation or untrusted user input, or tracing complex state mutations without stepping through a live debugger.

ripwire-rs --clones [--min-tokens <N>]
Hygiene
What It Does

Scans the codebase for duplicate logic, grouping candidate functions into exact (Type-1), renamed identifier (Type-2), and near-miss gapped (Type-3) clone groups.

How It Works

Tokenizes function bodies while skipping comments and string literals, computes $k$-gram token window hashes with in-place sort-dedup, evaluates Jaccard similarity, and validates near-misses via Longest Common Subsequence (LCS).

When To Use It

During code audits to consolidate duplicate utility routines into shared helpers, or to prevent boilerplate copy-pasting in team workflows.

ripwire-rs --callers <SYM> / --callees <SYM> / --find-symbol <SYM>
Navigation
What It Does

Emits the 1-hop neighborhood of a symbol: all direct incoming callers, outgoing callees, definitions, and ambiguity metrics formatted as XML. Works seamlessly across code symbols and database tables (e.g. ripwire-rs . --callers=user_accounts lists all functions across Dart, Rust, Python, TypeScript, Go, etc. that query or mutate that table).

How It Works

Interns <SYM> in $O(1)$ to find matching graph node IDs and directly indexes the CSR row offsets and target vectors without iterator allocations.

When To Use It

When tracing call hierarchies, checking who invokes a utility function, or inspecting the dependencies invoked by a given method.

ripwire-rs --impact <SYM> [--impact-depth <N>]
Navigation
What It Does

Computes the full transitive downstream blast radius of modifying <SYM>, ranking all dependent symbols by PageRank influence. Automatically traces blast radius across language boundaries—including from .sql migration files through to application services and test suites that touch altered tables (pairs with --affected, --test-gate, and --situ).

How It Works

Seeds Personalized PageRank with mass focused on <SYM> and runs power iteration across outgoing call edges to measure relative dependency concentration.

Unbound candidate calls appear separately as <dc> rows, not graph edges. dc_shown of declined_calls says how many a capped list holds; raise --token-budget to show more.

When To Use It

Before deprecating, modifying, or removing a core interface, data structure, or shared utility function to determine the full scope of downstream impact.

ripwire-rs --uses <SYM>
Lineage & Uses
What It Does

Emits every statically resolvable use-site of <SYM> across the repository (calls, reads, writes, imports, inheritance)—including cross-language embedded SQL table lineage extracted automatically from application string literals.

Lists every indexed site by default. Use --limit=N --offset=M for a path-and-line ordered window, then continue at next_offset.

How It Works

Zero extra flags required. During standard AST ingestion across all 36 languages, string literals containing SQL DML (SELECT ... FROM, JOIN, INSERT INTO, UPDATE, DELETE FROM) automatically emit RefRole::Read and RefRole::Write references attributed to the enclosing function or method, resolving directly to .sql table definitions in the workspace graph.

Python, JavaScript/TypeScript, and Rust also index bare non-local variable reads, excluding bindings, writes, labels, and lexical shadows. Grep's reads and reads_at use these references rather than text estimates; unsupported binding forms remain evidence floors.

When To Use It

When refactoring database schemas or migrating tables (e.g. ripwire-rs . --uses=user_accounts) to identify every backend service, repository method, query function, or migration touching that table.

ripwire-rs --path-between <A:B>
Architecture
What It Does

Finds the shortest directed call chain connecting symbol A to symbol B, returning the exact hop-by-hop sequence of intermediate functions.

How It Works

Executes bidirectional breadth-first search (BFS) over the resolved directed CSR call graph edges, returning reachability and hop count.

When To Use It

Investigating how an API controller reaches a database query, or checking for unintended architectural layer breaches between disparate modules.

Visualization

How It Works

ripwire-rs . --grep <PAT> [--grep-in code|any] [--grep-scope line|file] [--and <PAT>] [--not <PAT>] [--in <PATH>]
Search
What It Does

Literal search with span tiering (code by default, --grep-in=any adds comments and strings), boolean filtering (--and, --not, --grep-scope) and path restriction (--in), annotating every hit with its enclosing AST definition and listing matches in off-index text files in a trailing <unindexed> element.

How It Works

Classifies code, comment, and literal spans through language semantics. Comments are withheld when code hits exist; strings ride along with fewer than eight code hits. The innermost AST byte span identifies each hit's enclosing symbol.

When To Use It

Finding symbol references or keywords scoped to a specific directory or parent module while excluding noise.

ripwire-rs mcp [PATH] [--scip <FILE>]
Integration
What It Does

Starts a persistent stdio JSON-RPC server implementing the Model Context Protocol (MCP) for AI coding assistants.

How It Works

Overlapping tools return canonical CLI XML/text in result.content[0].text, with identical facts, defaults, errors, limits, grouping, provenance, and declined evidence. Maps default to 200 symbols / 65536 bytes; rank signals are pagerank, authority, hub, degree, ccx, and stable (unknown signals error). Connect defaults to radius 2. Situational awareness emits ripwire-rs.situ/v1 XML. Slice shares CLI root, flow/depth validation, and errors.

Impact's optional MCP max_depth matches global CLI --impact-depth=N, also with navigate --impact. Reports preserve legends without session mutation. CLI --json preserves XML hierarchy and text/CDATA: root tag/attributes/items, leaf text, mixed text interleaved in items, reserved-name attributes under attributes, and namespaced names as {uri}local; malformed reports error. Batch uses the real root and shared registry, caps both transports at 16, and rejects recursive batches/writes per item.

Batch success entries retain tool/result/kind (xml|text|json); malformed names fail per item, and CLI XML safely escapes text/JSON results. MCP owners accepts integer detail > 0; whereis accepts listing=defs|refs|all and boolean full_text, rejecting invalid listings. Detail 2 includes all requested bodies with accurate shown/total; root/revision and effective connect radius remain canonical.

When To Use It

In any MCP-compatible client or coding agent to equip AI workflows with native code intelligence tools.

Pre-Commit Verification Gates

Ripwire integrates directly into pre-commit workflows and CI/CD pipelines to prevent regressions:

  • Contract Breakage (--edit-check): Verifies if modifying a symbol changes parameter counts or visibility modifiers, identifying all 1-hop callers that become incompatible.
  • Test Reachability (--affected): Traverses transitive reverse call graph edges to surface exactly which test files reach the changed symbols or files.
  • Quality Delta (--quality-delta): Compares the working tree against git HEAD across 10 defect vectors (cognitive complexity, cyclomatic complexity, dead code, duplicates, nesting, params, churn, and arity breaks; exits 2 on regression). --quality-delta=REV measures from the merge base of REV instead.
  • Test Obligations (--test-gate): Names tests to run and highlights untested blast radius symbols (exits 4 if modified code leaves untested obligations).
  • Integration Seams (--seams): Discovers untested cross-module call boundaries between distinct subsystems.
  • Map Diff (--map-diff): Re-ranks architecture map toward git-changed files so active work automatically floats up in agent context windows.
  • Composite PR Context (--pr-context): Generates an all-in-one PR review context bundle vs a base reference, combining the symbols that own changed lines, caller files, tests with their run commands, co-change, and authors.
  • Merge Scout (--merge-scout): Predicts symbol and semantic merge conflicts across concurrent divergent branches before merging or rebasing.
  • Architectural Layering (--arch): Enforces strict directional layering constraints and prohibited dependencies from a rules file (exits 2 on violation).
  • Situational Awareness (--situ): Computes 5-point diff situational awareness: blast radius, tests to run, forgotten co-change partners, hotspots, and modules touched.

Algorithms & Academic Lenses

ripwire-rs implements 11 academic and algorithmic lenses over codebase graphs and behavioral histories:

  • Personalized PageRank: Power iteration over transpose in-edge CSR matrix with dangling mass redistribution. 1024-block reduction sums with early convergence checking.
  • Kleinberg HITS (Hubs & Authorities): Coupled iterative eigenvector convergence distinguishing core utility APIs (authorities) from orchestrators and test suites (hubs).
  • Louvain Community Modularity: Partitions the call graph into architectural modules by maximizing Newman-Girvan modularity (modularity) with deterministic tie-breaking.
  • AST Clone Detector: Token-level normalization detecting exact Type-1, renamed Type-2, and near-miss Type-3 gapped duplicates with $k$-gram Jaccard prefiltering and LCS.
  • ARISE Slicing: Intra-procedural forward and backward def-use dataflow slicing tracing reaching definitions and assignment propagation (arXiv:2605.03117).
  • Fowler's Co-Change Mining: Exponential half-life decay weighting commits over time to expose hidden Shotgun Surgery change coupling.
  • Maintenance Hotspots: Multiplies historical change frequency (churn) by cognitive complexity to surface defect-prone hotspots (software maintenance).
  • McCabe Cyclomatic & Essential Complexity: Counts independent control flow paths ($M = E - N + 2P$) and essential unstructured jump complexity.
  • Posnett Code Readability: Information-theoretic readability metric combining entropy, Halstead volume, line length, and identifier vocabularies (Posnett et al.).
  • Language-Agnostic Embedded SQL Lineage: Zero-flag, automated SQL DML extraction across string literals in all 36 host languages. Maps SELECT ... FROM and JOIN to RefRole::Read, and INSERT INTO, UPDATE, DELETE FROM to RefRole::Write, directly bridging relational database schemas (.sql files) to application services and test suites in the global call graph.

Rust Library API

Embed ripwire-rs directly into your Rust developer tools, custom CLI utilities, or AI agent runtimes: 

// Cargo.toml
[dependencies]
ripwire-rs = "0.6"

// src/main.rs
use ripwire_rs::ingest::{LanguageRegistry, ingest_in_memory_files};
use ripwire_rs::{Graph, Interner, Lang, PageRankConfig};

fn main() {
    let interner = Interner::new();
    let registry = LanguageRegistry::new();
    let files = [("src/main.rs", Lang::Rust, b"fn main() { run(); }\nfn run() {}" as &[u8])];
    let ingest = ingest_in_memory_files(&files, &registry, &interner);

    let graph = Graph::build(&ingest, &interner);
    let pr = graph.page_rank(&PageRankConfig::default());

    println!(
        "Indexed {} symbols and {} edges (iters={})",
        ingest.symbols.len(),
        graph.edge_count(),
        pr.iterations
    );
}
