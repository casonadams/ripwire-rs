Enforcing ripwire-rs Gates with a Hook

Block git commit until ripwire-rs verification passes. A hook runs the gate for you, so it cannot be skipped.

Set Up the Hook
Setup

Instructions get skipped; a hook cannot be. A hook runs your command before git commit and blocks it on a non-zero result, so the gate does not depend on anyone remembering to run it.

oh-my-pi (omp): the gate plugin

gate is a ready-made plugin in the casonadams/omp-plugins marketplace. It needs ripwire-rs on PATH, falls back to ripwire, and passes with a note when neither is installed. 

omp plugin marketplace add casonadams/omp-plugins
omp plugin install gate@casonadams-plugins

On every git commit run through the tool's shell, the plugin checks what differs from HEAD, one step at a time, and stops at the first step that fails:

  1. ripwire-rs . --edit-check="<symbol>" for each public symbol the diff adds or changes. Blocks when a contract changed and a caller no longer fits.
  2. ripwire-rs . --quality-delta. Blocks when it exits 2 (gating regressions).

Only when both are green does it list, without blocking, the untested rows from --test-gate and the files --situ says usually change with these. A failing step is reported alone ("BLOCKED at step 2 of 2, quality-delta"), so you fix one thing and commit again. Before a turn that changed source ends, it asks for a one-line Gate: summary, once per working-tree state. Pin a baseline at the start of a task (ripwire-rs . --quality-baseline) or --quality-delta has nothing to compare with. Set OMP_GATE_DISABLE=1 to turn it off.

Other tools

Any tool with a hook that runs before a shell command can do the same. The contract is small:

  • Trigger on a shell command that runs git commit, not on text that merely mentions it.
  • Run the steps above in order in the repository being committed, stopping at the first non-zero result.
  • Block the command and return the failing step's output as the reason.

The plugin's source is a reference implementation of each part, including finding the repository a command changes into (cd dir, git -C dir).
