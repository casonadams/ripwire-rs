PRACTICAL GUIDE · 7 PRIMARY WORKFLOWS

When, Where, & Why to Use ripwire-rs

ripwire-rs is engineered around 5 workflows: from landing cold in a foreign codebase to surgical test execution and automated CI/CD PR verification.

1. Orientation & Scoping 2. Navigation & Blast Radius 3. Pre-Commit & PR Gates 4. Code Health & Auditing 5. CI / CD & PR Gates
1. Orientation & Scoping: Landing Cold in a Repository
Scoping
When & Where
  • ▸First time inspecting or onboarding into an unfamiliar codebase.
  • ▸Starting a new issue or feature request.
  • ▸Feeding high-level, budget-bounded context to an AI coding agent without blowing prompt token limits.
Instructions & Commands
1 Architecture map of top 200 ranked symbols by Personalized PageRank
ripwire-rs . --top-k=200
2 File-by-file structural inventory showing top 3 symbols per file
ripwire-rs . --tree
3 Task-lens relevance ranking: retrieves ranked declarations relevant to a goal
ripwire-rs . --for="implement user authentication"
4 Export interactive, self-contained SVG/HTML call graph to open in browser
ripwire-rs . --html=graph.html --color-by=community
Why & Key Benefits
  • Zero Hallucinated Dependencies: Emits an in-context AST schema dictionary defining minified keys (t, n, sc, k, c).
  • Prompt Token Economy: Emits shown="K" truncation disclosures so models know absence in a top-slice does not mean absence in the repo.
  • Instantaneous Speed: Renders entire repository topologies in ~25 milliseconds.
2. Navigation & Blast Radius: Safe Refactoring & Impact Analysis
Refactoring
When & Where
  • ▸Before modifying a function signature or renaming a shared symbol.
  • ▸During incident investigation to trace caller paths and root causes.
  • ▸Measuring the blast radius of modifying a core data model or interface.
Instructions & Commands
1 Query direct 1-hop callers that depend on a symbol
ripwire-rs . --callers="Interner::len"
2 Query outgoing dependencies called by a function
ripwire-rs . --callees="ingest_files"
3 Transitive reachability graph: full blast radius across the whole codebase
ripwire-rs . --impact="Interner"
4 Local ego-graph neighborhood (depth=1..3, fanout=32)
ripwire-rs . --around="execute_query" --around-depth=2 --around-fanout=16
5 Shortest directed call path between two functions
ripwire-rs . --path-between="parse,serialize"
6 ARISE intra-procedural def-use variable dataflow slicing (forward/backward)
ripwire-rs . --slice="compute:x" --slice-flow=both
Why & Key Benefits
  • Zero Surprise Breakages: Answers "Can I safely change this?" with exact static call graph reachability instead of text search guesses.
  • Ambiguity Disclosure: Labels how each call edge bound (prov="import", prov="final-segment", prov="split"; caller rows of_def="K~s" / "K~n") and lists call sites the resolver declined as <dc> rows.
  • Deep Disambiguation: Supports flexible selectors (bare_name, Scope::name, file:name, file::Scope::name).
3. Pre-Commit & PR Safety Gates: Zero Broken Contracts
Safety Gate
When & Where
  • ▸In a hook that runs before git commit (see Hooks).
  • ▸Before running git push or opening a pull request.
  • ▸In automated CI/CD pull request verification gates before merging code.
Instructions & Commands
1 Verify caller compatibility after modifying a symbol contract
ripwire-rs . --edit-check="symbol_name"
2 Transitive reachability mapping to affected test suites
ripwire-rs . --affected="src/lib.rs"
3 Pre-PR gate: names tests to run and untested blast radius (exits with code 4)
ripwire-rs . --test-gate
4 Canonical situ/v1 XML for working tree diff: blast radius, tests, co-change
ripwire-rs . --situ
5 Assess whether a symbol can be safely deleted without breaking callers
ripwire-rs . --safe-delete="Interner::len"
6 Measure code quality regressions against git HEAD across 10 facets
ripwire-rs . --quality-delta
Why & Key Benefits
  • Surgical Test Execution: Identifies the exact test files that transitively reach your changes, so you run only those tests.
  • Contract Breakage Prevention: Catches parameter count changes and visibility regressions across all direct callers before you commit.
  • Fowler's Shotgun Surgery Protection: Surfaces companion files historically edited with your diff that you may have forgotten to update.
4. Code Health & Technical Debt Auditing
Architecture
When & Where
  • ▸During sprint refactoring cycles and technical debt burn-downs.
  • ▸Architectural reviews and modularity health checks.
  • ▸Eliminating dead code, near-miss duplicates, and unreferenced packages.
Instructions & Commands
1 Detect internal functions with zero incoming callers across the repository
ripwire-rs . --dead-code
2 Rank repository files by maintenance risk (churn * cognitive complexity)
ripwire-rs . --hotspots
3 Detect AST code clones and near-miss duplicates (Type-1, Type-2, Type-3)
ripwire-rs . --clones --min-tokens=40
4 Mine historical Git co-change coupling to identify hidden file coupling
ripwire-rs . --cochange
5 Partition call graph into cohesive modules via Leiden community detection
ripwire-rs . --communities
6 Discover symbols referenced in code but never defined (stdlib & external packages)
ripwire-rs . --external-surface
Why & Key Benefits
  • Data-Driven Focus: Prioritizes refactoring where maintenance churn intersects with elevated cognitive complexity.
  • Safe Dead-Code Pruning: Pinpoints zero-caller functions with mathematical certainty without manual grep sweeps.
  • Architectural Clarity: Detects tangled module boundaries and cyclic dependencies.
5. Continuous Integration (CI) Workflows & Automated PR Gates
CI / CD
When & Where
  • ▸Automated GitHub Actions (.github/workflows/), GitLab CI, or Jenkins pipelines.
  • ▸Enforcing pull request quality standards and preventing regressions before merge.
  • ▸Validating 1:1 behavioral parity against upstream specifications.
Instructions & Commands
1 PR Situational Awareness: canonical situ/v1 XML with blast radius, reaching tests, and co-change
ripwire-rs . --situ
2 Architectural Boundary Gate: enforces module layering rules (exits code 2 on violation)
ripwire-rs . --arch=rules.txt
3 Test Reachability Gate: blocks merge if changes leave untested blast radius (exits 4)
ripwire-rs . --test-gate
4 Quality Regression Gate: blocks merge if complexity, nesting, or AST clones regress vs base
ripwire-rs . --quality-delta
CI Pipeline Recipe · GitHub Actions Example

Add this workflow file to .github/workflows/ripwire-rs-gate.yml to enforce the 4 static verification gates on every PR, post situational awareness to the review UI, and block untested code before merge.

.github/workflows/ripwire-rs-gate.yml 
name: ripwire-rs PR Safety Gates
on:
  pull_request:
    branches: [main, master]

jobs:
  ripwire-rs-gate:
    name: Architecture, Quality & Safety Gates
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install ripwire-rs CLI
        run: cargo install ripwire-rs

      # 1. Post Situational Awareness directly to GitHub PR Summary
      - name: Generate PR Situational Awareness Report
        run: |
          echo "### ripwire-rs Situational Awareness" >> $GITHUB_STEP_SUMMARY
          echo '```' >> $GITHUB_STEP_SUMMARY
          ripwire-rs . --situ >> $GITHUB_STEP_SUMMARY
          echo '```' >> $GITHUB_STEP_SUMMARY

      # 2. Architectural Boundary Gate (if rules.txt exists)
      - name: Enforce Architecture Layering Rules
        run: |
          if [ -f rules.txt ]; then
            ripwire-rs . --arch=rules.txt
          fi

      # 3. Test Reachability Gate (exits code 4 on untested blast radius)
      - name: Run Test Reachability Gate
        run: ripwire-rs . --test-gate

      # 4. Quality Delta Regression Gate (exits non-zero on regressions vs base branch)
      - name: Run Quality Regression Delta Gate
        run: ripwire-rs . --quality-delta

      # 5. Run Test Suite
      - name: Run Tests
        run: cargo test --all
Why & Key Benefits
  • Automated Merge Blocking: Fails PR jobs automatically (exit code 4 on ripwire-rs . --test-gate or non-zero on ripwire-rs . --quality-delta) before untested code or architectural rot merges.
  • Sub-50ms Execution: Fast in-memory static analysis executes in milliseconds, eliminating slow CI runner bottlenecks.
  • Architectural Boundary Enforcement: ripwire-rs . --arch=rules.txt enforces layering rules and prevents circular module dependencies.
  • Zero Configuration: Reads native git repository history, remotes, and branch merge bases automatically.
