Built-in MCP Tools

Engineered for Agentic Workflows

Delivering dense, deterministic signal to LLMs without token bloat or hallucinated imports.

Personalized PageRank Impact

Calculates the transitive blast radius of any symbol modification. Pinpoint affected callers and contract breaks up to 16 hops deep before landing changes.

Pre-Commit Quality Delta Gates

Enforces cognitive complexity bars, contract arity checks, and test reachability against git HEAD. Flags regressions early in CI/CD or local pre-commit hooks.

Stdio MCP Context Tools

Native Model Context Protocol implementation exposing exploration, blast radius query, file splicing, doc drift, and variable slicing to any MCP-compatible coding agent.

ARISE Variable Slicing

Intra-procedural forward and backward def-use dataflow slicing. Trace exact parameter mutations and variable lifetimes without running the program.

Fowler's Co-Change Mining

Analyzes historical git commit topology to surface hidden coupling and shotgun surgery risks. Know which companion files always change together.

Zero-IO Architecture

Vendored Tree-Sitter grammars compiled directly into the binary with lock-free string interning via Lasso and parallel traversal via Rayon.

Embedded SQL Table Lineage

Zero-flag, language-agnostic extraction of embedded SQL DML (SELECT, INSERT, UPDATE, DELETE, JOIN) across string literals in all host languages. Resolves table read/write lineage directly to .sql definitions, linking migrations, backend services, and tests.

Multi-Agent Fleet Orchestration

Carve task context into a shared core plus N Leiden-community subagent slices (--pack-task --partition=N), predict parallel worktree collisions and landing order (--plan-lanes), and scout multi-branch merges (--merge-scout).

100% Local & Zero Telemetry

Air-gapped by design. Zero network calls, zero tracking, zero model training, and zero data leakage. Code never leaves your workstation; ripwire-rs purely extracts local AST context for your chosen agent harness. Automated secret redaction enabled by default.

36 Supported Languages

First-class tree-sitter AST queries extracting definitions, function signatures, and call sites—with automatic cross-language embedded SQL table lineage extracted from string literals in all 36 languages.
